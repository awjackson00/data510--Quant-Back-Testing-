Reproducing the analysis

Reproducibility depends on preserving three things exactly: the portfolio definitions, the regime date ranges, and the analysis window (January 1, 2000 – May 1, 2025). Yahoo Finance may revise historical adjusted prices, so a fresh pull may differ slightly from the results reported here.

  1. Clone the repository

    All source notebooks, portfolio construction code, and the final write-up live in the capstone repo.

    git clone https://github.com/awjackson00/data510-Quant-Back-Testing.git
cd data510-Quant-Back-Testing

  2. Install dependencies

    The primary stack is Python, NumPy, pandas, yfinance, Tidy Finance, matplotlib, seaborn, statsmodels, and scikit-learn. Use a virtual environment to keep versions isolated.

    # from the repo root
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

  3. Pull historical price data

    Prices are fetched live from Yahoo Finance via yfinance — no raw market data is redistributed in the repository, so this step requires network access. Running the EDA notebook rebuilds the daily price and daily-return series for every ticker used across the five portfolios.

    jupyter lab "notebooks/EDA Capstone.ipynb"

  4. Construct the portfolios

    Run portfolioConstruction.ipynb to apply the documented weighting rules: fixed 95/5 for Barbell, dynamic equal weighting for Mega-Cap Technology and Energy (so pre-IPO names aren't treated as existing historically), 100% VNQ for Real Estate, and equal 10% weights for FMCG.

  5. Assign regimes and compute metrics

    Run SharpeRatioSheet.ipynb. This is the notebook of record for Table 1 — it labels each daily observation with one of the nine regime windows and computes annualized return, annualized volatility, Sharpe ratio (excess return over the risk-free rate, annualized by √252), and Sortino ratio (same excess return, but scaled by downside deviation) for every portfolio × regime pair.

  6. Reproduce the visualizations

    Figures 1–3 (rolling one-year Sharpe, benchmark cumulative returns, and portfolio-vs-benchmark cumulative returns by regime) are generated from the same regime-labeled return series produced in the previous step.

  7. Optional: rerun the ARIMA baseline

    ARIMA Time-Series Modeling.ipynb applies the Box–Jenkins framework via statsmodels to each portfolio's daily return series. This step is not required to reproduce the core resilience results and is included for completeness — the project reports it as an inconclusive null result.

Known reproducibility caveats

Data revisions

Yahoo Finance may revise historical adjusted prices or ticker availability after the fact, so a later pull may not match the reported figures exactly.

Asset inception dates

VNQ (2004) and IEF have no Dot-com-era coverage. Dynamic equal weighting handles this for the multi-stock portfolios, which means their composition is not perfectly constant through time.

VIX is not investable

The Barbell portfolio's 5% VIX sleeve is an analytical proxy for volatility exposure, not a tradable position. Treat Barbell as a theoretical comparison rather than an implementable strategy.

Short regimes annualize loudly

Regional Banking Stress covers only three months. Annualizing a short window can produce very large numbers (Mega Tech's 117.08%) — read those alongside the cumulative-return figures, not in isolation.
